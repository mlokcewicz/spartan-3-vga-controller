# spartan-3-vga-controller

Simple VGA controller demo for the Digilent Basys 2 FPGA development board.

## Capabilities

* 640x480 VGA output
* HSYNC and VSYNC signal generation
* Simple RGB test pattern
* 25 MHz pixel clock
* Simple RGB graphics
* On-screen object controlled with 4 push buttons
* Background color/pattern controlled with slide switches

## Hardware

* Digilent Basys 2
* Xilinx Spartan-3E XC3S100E-4CP132

## Tools

* VHDL
* Xilinx ISE Design Suite 14.7
* Digilent Adept 2
